# Cierre de caja

App web ligera para calcular el cuadre, el retiro y el arqueo al cerrar caja, con una calculadora para contar billetes y monedas.

**App:** https://edwbryan.github.io/cierre-caja/

Los valores de cada tienda (monto objetivo de bóveda, límite por retiro, precios, avisos) no están en el código: se ponen en **Ajustes** y se guardan solo en el celular. Nada se envía a ningún servidor.

> **Aviso:** proyecto personal y no oficial. No está afiliado, patrocinado ni aprobado por ninguna empresa. Los cálculos son una ayuda; verifica siempre con el sistema de tu tienda.
